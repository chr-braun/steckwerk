Hinter den KulissenBehind the scenes

Wie aus Maßen Teile werden.How measurements become parts.

Steckwerk zeichnet nichts von Hand. Jedes Modell ist ein kleines Programm, das aus deinen Werten die Konturen errechnet, die Schnittbreite des Lasers ausgleicht und alles prüft, bevor eine Datei entsteht. Auf dieser Seite siehst du, wie das abläuft, und wie du selbst ein Paket mit eigenen Modellen baust.

Steckwerk draws nothing by hand. Every model is a small program that computes the outlines from your values, compensates for the laser’s kerf and checks everything before a file is written. This page shows how that works, and how to build your own package with your own models.

So rechnet Steckwerk.How Steckwerk computes.

Fünf Schritte, jedes Mal, wenn du einen Wert änderst. Auf einem neueren Mac dauert das meist weniger als eine Sekunde.

Five steps, every time you change a value. On a recent Mac this usually takes less than a second.

  1. Werte sammelnCollect the values

    Aus dem Formular kommen die Maße des Modells, dazu aus dem Materialprofil die Materialstärke T und die Schnittbreite (Kerf), zum Beispiel Pappel 3 mm mit 0,15 mm. Alle Maße sind Millimeter.

    The form supplies the model’s sizes, and the material profile adds the material thickness T and the kerf, for example poplar 3 mm with 0.15 mm. All sizes are millimetres.

  2. Teile konstruierenConstruct the parts

    Die Funktion build() des Modells zeichnet jedes Teil als Kontur: Außenkante, Löcher, Gravurlinien. Zinken und Schlitze richten sich nach T, damit ein Haus aus 4 mm Holz genauso zusammengeht wie eines aus 3 mm. Verzierungen wie Fenster, Ranken oder Schrift setzt ein Baukasten so, dass sie nie eine Schnittkante berühren.

    The model’s build() function draws each part as an outline: outer edge, holes, engraving lines. Tabs and slots follow T, so a house made from 4 mm wood fits together just like one made from 3 mm. Decorations such as windows, scrolls or lettering are placed by a toolkit that keeps them clear of every cut edge.

  3. Schnittbreite ausgleichenCompensate for the kerf

    Der Laser brennt eine Fuge von etwa 0,1 bis 0,2 mm weg. Steckwerk verschiebt deshalb jede Kontur um die halbe Schnittbreite nach außen ins Material: Außenkanten werden etwas größer, Löcher und Schlitze etwas kleiner. So sitzen Steckungen nach dem Schneiden stramm.

    The laser burns away a gap of about 0.1 to 0.2 mm. Steckwerk therefore moves every outline outwards into the material by half the kerf: outer edges get slightly bigger, holes and slots slightly smaller. That way joints sit tight after cutting.

    SollmaßNominal size Schnittlinie mit Ausgleich (hier stark vergrößert)Cut line with compensation (exaggerated)

  4. PrüfenCheck

    Der Validator geht jedes Teil durch: Sind alle Konturen geschlossen und kreuzungsfrei? Bleibt zwischen zwei Schnitten mindestens 1 mm Material stehen? Findet jeder Zinken seinen Schlitz, mit passender Breite und Tiefe? Passt alles auf die Platte? Gibt es auch nur einen Fehler, wird nichts geschrieben, und der Prüfbericht sagt, welches Teil wo hakt.

    The validator goes through every part: are all outlines closed and free of crossings? Is there at least 1 mm of material between two cuts? Does every tab find its slot, with matching width and depth? Does everything fit on the sheet? If there is a single error, nothing is written, and the check report says which part fails where.

  5. Anordnen und ausgebenLay out and export

    Die Teile werden dicht auf eine oder mehrere Platten verteilt und mit Teilenummern versehen. Heraus kommt eine SVG mit zwei Ebenen, Schnitt in Schwarz und Gravur in Blau, und auf Wunsch ein fertiges Projekt für xTool Creative Space, eine Montageanleitung als PDF und eine Schätzung von Laserzeit und Materialkosten.

    The parts are packed tightly onto one or more sheets and numbered. The result is an SVG with two layers, cut in black and engraving in blue, and on request a ready project for xTool Creative Space, an assembly guide as a PDF and an estimate of laser time and material cost.

Ein eigenes Paket bauen.Build your own package.

Ein Paket ist ein Ordner mit einem Steckbrief und je Modell einer Python-Datei. Du brauchst Python 3.8 oder neuer und das Steckwerk-Repo, sonst nichts.

A package is a folder with a short manifest and one Python file per model. You need Python 3.8 or later and the Steckwerk repo, nothing else.

  1. Vorlage anlegenCreate a template

    Steckwerk legt dir einen Ordner mit einem lauffähigen Beispielmodell an.

    Steckwerk creates a folder with a working example model for you.

    python3 cli.py --paket-neu krippe --out meine-pakete

meine-pakete/krippe/
  paket.json      Steckbrief
  krippe.py       ein Modell je Datei

  2. Steckbrief ausfüllenFill in the manifest

    In paket.json stehen Name, Version und die Modelle. Wer Ornamente und Steckhelfer der anderen Pakete nutzen will, trägt Grundlagen unter benoetigt ein; Steckwerk installiert es dann mit.

    paket.json holds the name, version and models. To use the ornaments and joint helpers of the other packages, list Basics under benoetigt; Steckwerk then installs it along.

    {
  "standard": 1,
  "id": "krippe",
  "name": "Krippe",
  "name_en": "Nativity",
  "version": "1.0.0",
  "beschreibung": "Stall mit Stern zum Stecken.",
  "steckwerk": "2.4.0",
  "benoetigt": {"verzierungen": "2.0.0"},
  "modelle": ["krippe"]
}

  3. Modell schreibenWrite the model

    Jede Modelldatei hat zwei Teile. INFO beschreibt das Formular, aus dem Steckwerk die Eingabefelder baut. build() bekommt die Werte und gibt die Teile zurück. Koordinaten sind Millimeter, y zeigt nach oben, Außenkonturen laufen gegen den Uhrzeigersinn.

    Every model file has two parts. INFO describes the form Steckwerk builds the input fields from. build() receives the values and returns the parts. Coordinates are millimetres, y points up, outer outlines run counter-clockwise.

    from steckwerk import Assembly, Part, circle, rect
from models import _deko as dk
from pakete import num, txt

INFO = dict(
    label="Türschild", group="Pakete",
    desc="Hängeschild mit Text und zwei Löchern.",
    params=[num("width", "Breite", 120, 60, 300),
            num("height", "Höhe", 60, 30, 200),
            txt("text", "Text", "Willkommen")])

def build(cfg, name="tuerschild", width=120.0, height=60.0, text="Willkommen"):
    W, H = cfg.s(width), cfg.s(height)
    part = Part(name, rect(-W / 2, 0, W, H))
    for x in (-W / 2 + 8, W / 2 - 8):                 # Aufhängelöcher
        part.add_hole(circle(x, H - 8, 2.0, cfg.arc_tolerance))
    cv = dk.Canvas(part, margin=2.0)                  # Gravur, die nie einen Schnitt berührt
    if dk.sign(cv, text, "holz", [(-W / 2 + 14, 4, W / 2 - 14, H - 14)],
               "normal", "gross", min_h=3.0, anchor="mitte") is None:
        raise ValueError("Der Text passt nicht aufs Schild.")
    asm = Assembly(name)
    asm.parts.append(part)
    asm.notes.append("Schild an einer Kordel aufhängen.")
    return asm

    Was nicht geht, meldest du mit ValueError und einem verständlichen Satz; der erscheint genau so in der App. Was in asm.notes steht, landet als Montagehinweis im Prüfbericht. Steckverbindungen zwischen Teilen beschreibst du mit JointFeature und asm.connect(), dann prüft der Validator auch Passung und Kerf.

    Report what isn’t possible with ValueError and a plain sentence; it appears exactly like that in the app. Whatever goes into asm.notes ends up in the check report as an assembly note. Describe joints between parts with JointFeature and asm.connect(), and the validator checks fit and kerf too.

  4. PrüfenCheck

    Steckwerk baut jedes Modell mit seinen Standardwerten und lässt den Validator darüber laufen. Erst wenn alles schnittfertig ist, geht es weiter. Zum Ausprobieren mit anderen Werten installierst du den Ordner direkt und startest die Browser-Oberfläche.

    Steckwerk builds every model with its default values and runs the validator over it. Only when everything is cut-ready do you move on. To try other values, install the folder directly and start the browser version.

    python3 cli.py --paket-pruefen meine-pakete/krippe
python3 cli.py --paket-installieren meine-pakete/krippe
python3 webui.py

  5. Packen und weitergebenPack and share

    Heraus kommt eine .swpaket-Datei. Die lädst du in Steckwerk unter Einstellungen → Pakete → Paket laden, oder du gibst sie weiter. Bei jeder Änderung die Version erhöhen.

    The result is a .swpaket file. Load it in Steckwerk under Settings → Packages → Load package, or pass it on. Raise the version with every change.

    python3 cli.py --paket-packen meine-pakete/krippe --out .
→ krippe-1.0.0.swpaket

Für die offiziellen Pakete.For the official packages.

Die Themenpakete im Update-Kanal entstehen genauso. Ihre Quellen liegen im Repo unter paketquellen/.

The theme packages in the update channel are made the same way. Their sources live in the repo under paketquellen/.

  • Ein Paket je Thema. Neue Modelle kommen in das passende Themenpaket, nicht in ein eigenes.
  • Bereich eintragen. Ein neues Paket bekommt in paketquellen/bereiche.json seinen Platz im Katalog.
  • Version erhöhen, Release starten. Der Release-Workflow packt jedes Paket, dessen Version im Kanal noch fehlt, und stellt es in den Update-Kanal. Steckwerk bietet es dann allen an.
  • Gemeinsame Werkzeuge nutzen. Mit pakete.bibliothek("verzierungen") stehen Rosetten, Ranken, Bordüren und Steckhelfer aus Grundlagen bereit.
  • One package per theme. New models go into the matching theme package, not into a package of their own.
  • Assign an area. A new package gets its place in the catalogue in paketquellen/bereiche.json.
  • Raise the version, start a release. The release workflow packs every package whose version is missing from the channel and puts it into the update channel. Steckwerk then offers it to everyone.
  • Use the shared tools. pakete.bibliothek("verzierungen") gives you rosettes, scrolls, borders and joint helpers from Basics.
